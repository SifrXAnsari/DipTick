# About DipTick

DipTick is a chat with models, one or several at a time, in one program that is a command line, a terminal screen and a window. It keeps your chats on this PC, asks you before an agent does anything you have not allowed, and writes every decision it makes to an audit log you can check.

This is DipTick {{version}}.

## No technical assistance

DipTick comes with no technical assistance of any kind. These pages are its documentation: Help (F1) in the window and the terminal screen, and `diptick docs` on the command line.

## Privacy

DipTick collects nothing about you, and never will. It has no telemetry, no account and no server of its own. Nothing is sent anywhere except to the providers and services you choose, and what you send them is between you and them: see [What providers see](what-providers-see). What DipTick keeps stays on this PC, in files that are yours: see [Your data](your-data).

There is no privacy policy, because there is nothing to disclose.
